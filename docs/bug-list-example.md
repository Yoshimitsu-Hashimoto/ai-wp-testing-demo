## 記入ルール

- バグIDは `BUG-01` から連番で付ける。
- 仕様IDは `docs/spec.md` の受け入れ条件のIDを書く。
- 期待結果は仕様書の記述に基づいて書き、推測で決めない。
- 証拠にはスクリーンショットやトレースのファイルパス、テストの実行記録を書く。
- 重要度は「高・中・低」のいずれか。判断基準は下の表のとおり。
- 対応状況は「未対応・修正中・再テスト済み」のいずれか。

## 重要度の判断

| 重要度 | 基準 | 該当 |
|---|---|---|
| 高 | 主要機能が仕様どおりに動かない、または個人情報の取り扱いに関わる | BUG-01（絞り込みという機能そのものが働かない）、BUG-03（同意なしに個人情報を受け付けてしまう） |
| 中 | 一部の条件で仕様どおりに動かない | BUG-02（任意項目が未入力の実績だけで起きる表示の不具合） |
| 低 | 表示上の問題など影響が小さい | なし |
